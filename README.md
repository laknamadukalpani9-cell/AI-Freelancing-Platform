# AI-Freelancing-Platform
AI Projects and Services Freelancing Platform - Database and Web Application
## Features

- User Registration and Login
- Freelancer Management
- Client Management
- AI Project Management
- AI Service Management
- Project Posting
- Proposal Submission
- Assignment Management
- Payment Management
- Review and Rating System
- Database Management
## Technologies Used

- C#
- ASP.NET Core
- .NET
- SQL Server
- SQL Server Management Studio (SSMS)
## Database Description

The system uses Microsoft SQL Server to store and manage data.

The database includes tables for:
- Users
- Freelancers
- Clients
- AI Projects
- AI Services
- Skills
- Proposals
- Assignments
- Payments
- Reviews

The database uses primary keys and foreign keys to maintain relationships between tables.
